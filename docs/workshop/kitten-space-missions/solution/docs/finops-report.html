🚀 4. Optimizaciones Recomendadas

💡 Optimización #1: Auto-Shutdown para Desarrollo

Ahorro Estimado: $5.25/mes (-40% en App Service cost)

Estrategia: Detener App Service Plan fuera de horario laboral (off-peak hours)

  • Schedule: Lunes-Viernes 8:00-18:00 CET (10 horas/día)
  • Uptime: 50 horas/semana = 200 horas/mes (27% uptime)
  • Savings: ~73% de ahorro en App Service ($13.14 → $3.54/mes)
  • Trade-off: No disponible 24/7 (aceptable para dev non-critical)

Implementación:

# Azure Automation Runbook (PowerShell)
Stop-AzWebApp -ResourceGroupName "rg-kitten-missions-dev" -Name "app-kitten-missions-dev"

# O con GitHub Actions (scheduled workflow)
- cron: '0 18 * * 1-5' # Stop at 18:00 Mon-Fri
- cron: '0 8 * * 1-5'  # Start at 8:00 Mon-Fri

✅ Recomendación: Implementar para dev environment. Costo mensual final: $15.70 (25% ahorro total).
