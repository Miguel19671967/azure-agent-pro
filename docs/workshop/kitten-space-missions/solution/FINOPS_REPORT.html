🚀 Oportunidades de Optimización

1. Auto-Shutdown para Desarrollo

💡 Ahorro Estimado: ~€5/mes (40% App Service cost)

Estrategia: Detener App Service Plan fuera de horario laboral

  • Horario activo: Lunes-Viernes 08:00-18:00 CET (10h/día)
  • Shutdown automático: Resto del tiempo (14h/día + weekends)
  • Ahorro: ~58% del tiempo (€12 → €7/mes)

Implementación: Azure Automation runbook o GitHub Actions scheduled workflow

2. Reserved Instances (Long-term)

💡 Ahorro Estimado: €3.60/mes (30% App Service cost)

Aplicable si el proyecto dura >6 meses:

Opción Costo Mensual Ahorro vs PAYG Break-even
Pay-as-you-go (actual) €12.00 - -
Reserved 1 año €8.40 30% (€3.60/mes) 4 meses
Reserved 3 años €7.20 40% (€4.80/mes) 5 meses

3. SQL Database Monitoring & Right-sizing

⚠️ Monitorear DTU Usage

Current: Basic (5 DTU, €4.50/mes)

Trigger para upgrade: Si DTU usage > 80% sostenido por 3+ días

Next tier: S0 (10 DTU, €13/mes) - 2x performance, 125x storage

Acción: Configurar alerta en Application Insights cuando DTU > 80%

4. Eliminar Private Endpoint (Alternativa)

⚠️ No Recomendado pero Posible

Ahorro potencial: €7/mes (26% del total)

Trade-off:

  • ❌ SQL Database accesible desde internet (con firewall rules)
  • ❌ Reduce nivel de seguridad (no Zero Trust)
  • ✅ Alternativa: Service Endpoints (gratis pero menos seguro)

Recomendación: Mantener Private Endpoint por seguridad, incluso en dev

5. Monitoring Free Tier Optimization

✅ Ya Optimizado

Application Insights + Log Analytics están configurados para mantenerse dentro del free tier (5GB/mes):

  • Sampling configurado al 100% en dev (todo el tráfico capturado)
  • Consumo esperado: ~500MB/mes (10% del free tier)
  • Retención: 30 días (óptimo para dev)
  • Sin cargos adicionales esperados
